# Bamboo Food

A Minecraft Bedrock Edition addon that adds various food and drink items with bamboo-based crafting.

## Features

- Various food and drink items
- Bamboo-based crafting recipes
- Custom textures and models
- Multi-language support (English and Polish)

## Installation

1. Go to the [Releases](../../releases) page
2. Download the latest `.mcaddon` file
3. Open Minecraft Bedrock Edition
4. Go to Settings > Global Resources > My Packs
5. Click "Import" and select the downloaded file
6. Activate the pack in your world
